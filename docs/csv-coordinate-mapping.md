# CSV 좌표 → Three.js 월드 좌표 매핑

CFD 결과를 경량화한 CSV(`x_m, y_m, t0000s … t1800s`)가 세굴/퇴적 3D 시각화에서 어떻게 월드 좌표와 시간 프레임으로 변환되는지 정리한 문서입니다.

관련 코드:

- `src/utils/parseScrdifTimeCsv.ts` — CSV 파서(스트리밍, 진행률·중지 지원)
- `src/data/buildScrdifDashboard.ts` — 지형 격자 보간, 시간별 프레임, 교각 검출
- `src/data/loadCsvDashboard.ts` — 업로드 로더(`CsvDashboardLoadResult`, 여러 케이스는 `loadCsvDashboards`)
- `src/components/CaseSwitcher.ts` — 뷰어의 케이스 전환 선택 상자
- `src/data/probeSeries.ts` — 시간별 평균 scrdif 요약(재생 시각 조회용)
- `src/constants/experiment.ts` — `CSV_STRUCTURE`(구조물 고정 조건)
- `src/modules/Terrain.ts` — 메쉬 정점 높이·색 렌더링

---

## 1. 입력 형식

```text
x_m,y_m,t0000s,t0030s,t0060s,…,t1800s
0.007424,-0.645000,0.0000000e+00,1.2767426e-12,…
0.022197,-0.645000,0.0000000e+00,1.6909724e-10,…
```

| 열 | 의미 |
| --- | --- |
| `x_m` | 흐름 방향(수조 길이) 위치, m |
| `y_m` | 횡단 방향(수조 폭) 위치, m |
| `tNNNNs` | NNNN 초 시점의 scrdif(초기 하상 대비 Δ표고), m. 음수=세굴, 양수=퇴적 |

- 한 행 = 하상 격자점 1개. 모든 시간 열이 같은 좌표를 공유합니다(좌표는 한 번만 저장).
- z(연직)는 없습니다. (x, y)마다 값이 하나뿐인 2D 하상 평면입니다.
- 유속(u, v, w)은 없습니다. 유속 기반 화면 요소(화살표·추적 입자·유체 물리량 색상)는 이 CSV로 만들 수 없어 숨깁니다.
- 파일 1개에 모든 구조물이 들어 있습니다(예: `s01_all_timesteps.csv`는 구조물 3개).
- 파일 1개 = 케이스 1개입니다. 여러 케이스(`s01`, `s02`…)를 함께 올리면(최대 `MAX_CSV_CASES` = 5개) 뷰어 왼쪽의 「케이스」 선택 상자로 바꿔 볼 수 있습니다. 전환해도 보던 시각과 재생 상태는 유지됩니다. 케이스 이름은 파일명에서 `.csv`와 `_all_timesteps`를 뗀 값입니다.

예시(`s01`): 27,300행 = 210(x) × 130(y), 시간 열 61개(0~1800초, 30초 간격).

## 2. 축 대응 (CSV ↔ Three.js)

| CSV | Three.js 월드 축 | 변환 |
| --- | --- | --- |
| `x_m` | X (흐름, +X 방향) | `worldX = x − centerX` |
| `y_m` | Z (횡단) | `worldZ = y − centerY` |
| scrdif | Y 변위 | `vertexY = scrdif × Z 스케일` |

`centerX = (minX + maxX) / 2`, `centerY = (minY + maxY) / 2`. 지형 격자가 월드 원점을 중심으로 놓이므로 CSV 영역 중심을 원점에 맞춥니다. `s01`에서는 `centerX = 0.85`, `centerY = 0`입니다.

---

## 3. 지형 격자 보간

CSV 점을 1:1로 찍지 않고, 고정 간격 지형 격자에 이중선형 보간합니다.

| 항목 | 값 |
| --- | --- |
| 셀 크기 | `FLUME.terrainCellSize` = 0.01 m |
| 정점 수 | `ceil(span / cellSize) + 1` (`s01`: 170 × 130) |
| 범위 | CSV x·y 범위 전체(수조 + margin 확장 없음) |

- x 간격은 균일하지 않습니다(약 0.005~0.0148 m). y는 0.01 m로 균일합니다. 그래서 CSV 쪽은 정렬된 축(`xs`, `ys`)에서 구간을 찾아 보간합니다.
- CSV 범위를 벗어난 정점은 가장 가까운 값을 씁니다(외삽 없음, 0으로 채우지 않음).
- `Float32` 좌표 오차로 정점 수가 하나 늘지 않도록 격자 스팬 계산에 허용치(`GRID_SPAN_EPS`)를 둡니다.

시간 프레임은 시간 열마다 하나입니다. 프레임이 `MAX_SCRDIF_FRAMES`(4096)를 넘으면 stride를 자동으로 올립니다.

## 4. 구조물(교각) 검출

CSV에는 구조물 좌표가 없습니다. 모든 시간(t0 제외)에서 값이 정확히 0인 셀 덩어리를 구조물이 차지한 영역으로 보고 교각을 검출합니다.

1. 모든 프레임에서 `|scrdif| ≤ 1e-12`인 셀을 표시합니다.
2. 8방향 연결 요소로 묶습니다.
3. 격자 가장자리에 닿거나 셀이 4개 미만인 덩어리는 제외합니다.
4. 덩어리의 bbox 중심을 교각 위치로 씁니다. 월드 z 오름차순으로 `P1…Pn`을 붙입니다.

`s01`·`s02` 모두 같은 위치에서 3덩어리(x≈0.85 m, y≈−0.27 / 0 / +0.27 m)가 검출됩니다. 담당자 확인: 구조물은 3개이고, 중앙 기둥은 x=0.85 m, y=0(전체 범위의 중앙)입니다. 검출된 P2(월드 x=0, z=0)와 일치합니다. 양쪽 두 기둥(y=±0.27 m)의 위치는 아직 담당자 확인 전입니다.

교각 크기는 CSV가 아니라 환경조건(`CSV_STRUCTURE`)을 씁니다.

| 항목 | 값 |
| --- | --- |
| 직경 | 0.0625 m |
| 노출 높이 | 0.30 m |
| 기초 근입(= 하단부 매립 높이) | 0.08 m |
| 모래지반 두께 | 0.08 m |
| 세굴 탐색 반경 | 교각 중심에서 직경의 2배 |

세굴 최대점은 교각 발 아래가 아니라 중심에서 약 0.09 m 떨어진 곳(좌우·상류)에 생기므로, 교각별 최대 세굴심은 위 탐색 반경 안에서 구합니다.

## 5. FLOW-3D 시나리오 연동

파일명이 `sNN`(`s01_all_timesteps.csv` → `s01`)이면 `FLOW 3D 시나리오.xlsx`의 시나리오 `SNN`과 연결합니다(`src/constants/scenarios.ts`, 엑셀에서 생성).

| 시나리오 값 | 적용 위치 |
| --- | --- |
| d50, 수심, 유속 | 케이스 적용 시 `SimParams`(입경·수심·유입 유속)에 반영. 수심은 「지형 위 수면」 높이로 쓰임 |
| 기둥 중심 간격 S | CSV에서 검출한 교각 간격 검증. 3개를 못 찾으면 중앙(월드 원점) 기준 ±S 배치로 대체 |
| 하단부 형상 | 정사각 0.13 × 0.13 / 원형 D 0.13 / 타원형·직사각형 0.26(+X) × 0.13. 높이 0.13 m 중 노출 0.05 m만 그림 |

- 뷰어 왼쪽 「케이스」 상자가 케이스별 시나리오 조건을 보여 주고, 기준(S01)과 다른 조건은 강조합니다.
- 시나리오와 CSV가 어긋나면(교각 개수·간격) 파싱 상태 줄과 토스트에 경고를 띄웁니다. 간격이 다를 때는 CSV 값을 따릅니다.
- 세굴 탐색 반경은 교각 직경의 2배와 인접 교각 간격의 절반 중 작은 값입니다(`S23`처럼 간격이 좁을 때 이웃 구덩이를 중복해서 세지 않기 위함).
- 하단부 중심은 교각 중심과 같다고 가정합니다(타원형·직사각형의 장축 위치는 데이터 확인 전).
- 파일명이 시나리오 규칙에 맞지 않으면 시나리오 없이 CSV 값만 씁니다.

## 6. 표시 정책

- **교각 주변만 표시**(기본 켬, 「케이스」 상자의 체크): 가장 상류 교각 앞 0.4 m ~ 가장 하류 교각 뒤 0.6 m, 바깥 교각 옆 0.3 m(`REGION_OF_INTEREST`, `s01`에서 x 0.45~1.45 m, |y| ≤ 0.57 m) 밖은 가장자리 0.08 m 구간에서 서서히 0으로 줄여 가립니다. `s01` 1800초 기준 세굴의 약 29%가 유입부(x<0.45 m, 맑은 물 유입으로 생기는 '배고픈 물' 세굴), 퇴적의 약 23%가 유출부(x>1.35 m)에 있어 교각 국부 세굴과 섞여 보이기 때문입니다. 끄면 CSV 전체를 그대로 봅니다. 교각별 세굴심(모니터·등급)은 교각 가까이만 보므로 이 설정과 무관합니다.
- **Z 스케일**(「케이스」 상자, 기본 ×1 = 실제 비율, 선택 ×1 / ×2 / ×4): 세굴·퇴적은 최대 2~3 cm 라서 ×1 에서는 거의 평평해 보입니다. 필요하면 지형 높이(Z)에만 배율을 곱합니다. 교각·하단부(노출 5 cm)는 키우지 않으므로, 배율이 크면 퇴적 둔덕(2 cm × 배율)이 하단부보다 높아 보이고 원본 값의 계단이 뾰족하게 드러납니다. ×4 에서는 4 cm × 2 = 8 cm 로 하단부(5 cm)를 넘어섭니다.
- 수면(「지형 위 수면」)은 기본으로 꺼 둡니다. 세굴 형상이 가려지지 않게 하기 위해서입니다.
- 유속 항목·추적 입자 UI는 숨기고 「하상 변화」만 남깁니다.
- 실측 CSV는 교각 세굴심에 표시용 배율(`pierScourDisplayScale`)을 적용하지 않습니다. 등급은 실측 세굴심 ÷ 기초 근입(0.08 m)으로 판정합니다.
- 세굴 최대 약 0.02~0.03 m라서 색 범례는 `±absMax`로 자동 맞춥니다.

## 7. 알려진 한계

- 값이 ±0.02 m 근처에서 계단식으로 clip된 것으로 보이며(원본 CFD 특성으로 추정), 지형에 격자 형태의 계단 무늬가 보일 수 있습니다.
- 격자 값에 시간 방향 잡음이 있습니다. 인접 시점 평균에서 2 mm 넘게 벗어난 값이 `s01`에서 약 1,900개(전체의 약 0.1%)입니다. `s01` 1380초의 −25.5 mm(다음 프레임 −20 mm)도 이 잡음의 극값이며 고립된 오류가 아니므로 보정하지 않고 실측 그대로 표시합니다. 색 범례·범위는 CSV 전체 min/max(`bounds`)를 쓰기 때문에 이 극값이 범위에 반영됩니다.
- 구조물 검출은 0 셀 덩어리에 의존합니다. 원본 FLOW-3D 설정과 다른 형식의 CSV는 별도 확인이 필요합니다.

## 8. 데이터 흐름

```text
CSV (x_m, y_m, t0000s … t1800s)
        ↓ parseScrdifTimeCsv      — 행×시간 Float32Array
        ↓ buildScrdifDashboard    — 지형 격자 이중선형 보간(프레임마다)
        ↓                         — 0 셀 덩어리 → 교각 P1…Pn
ScourSeries + PierDefinitionMeta[]
        ↓
Terrain.ts / PierMarker           — 정점 Y = scrdif, vertex color = f(scrdif)
```
